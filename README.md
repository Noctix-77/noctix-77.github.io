# Portfolio professionnel — Sahad Safeer

Portfolio BTS SIO SLAM conservant l'identité visuelle de l'ancien univers « Prince of Spiders ».

## Fichiers principaux

- `index.html` : portfolio principal en une page.
- `style.css` : styles, responsive, loader et composants.
- `main.js` : navigation, animations, filtres, formulaire et loader.
- `roses.js` : roses décoratives Three.js.
- `realisation.html` : modèle de fiche détaillée.
- `realisations-data.js` : contenu des fiches de réalisations.
- `realisation.js` : rendu dynamique d'une fiche.

## Photo

## Formulaire de contact

Le formulaire valide les champs puis ouvre actuellement le client de messagerie avec le message prérempli. Pour un envoi directement depuis le site, il faudra connecter un backend ou un service de formulaire (Formspree, Web3Forms, etc.) afin de ne pas transmettre les messages à un tiers sans choix explicite.
